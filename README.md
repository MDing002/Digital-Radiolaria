# Introduction
This repository contains the source files for Digital Radiolaria, the WCC2 final project by Man Ding.
The project includes one TouchDesigner file and one Max/MSP file.
The system is based on a MediaPipe integration shared by torinmb.
Before running the project, you must download the required release files.
# How to Download the Required Release Files
The project depends on the MediaPipe–TouchDesigner setup provided by torinmb:
https://github.com/torinmb/mediapipe-touchdesigner
I used the “Download Latest Release” file provided in their README.
For convenience, the same release file is also available here:
https://drive.google.com/file/d/1yPqqj3QqJ6UO07IZEzykWWHjhKnoisxK/view?usp=drive_link
# How to Run the Project
Please download the TouchDesigner and Max files and run them simultaneously on the same computer.
Follow the instructions provided in the comments within the files.
Each time the TouchDesigner file is opened, locate MediaPipe TouchDesigner.toe from the downloaded release folder, and re-copy the missing MediaPipe and hand_tracking2 components into the project.
